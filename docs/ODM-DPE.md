# ORDRE DE MISSION MAÎTRE — VERRIÈRE
## Micro-application DPE — lecture exhaustive, hiérarchisation et restitution

> Reçu d'Aude le 21/08/2026. **Référence de travail pour toute la
> micro-application DPE.** Il complète et, en cas de contradiction, remplace les
> consignes antérieures moins exigeantes.

## 0. Statut

Contrainte absolue, permanente et non négociable : **EXCELLENCE + COMPLÉTUDE +
FIABILITÉ**.

Un DPE n'est jamais « lu » parce que sa classe énergétique, son GES et sa
consommation ont été extraits. Un DPE est la **description énergétique complète
d'un bâtiment**. La mission de Verrière est de répondre simplement à :

> Pourquoi ce logement obtient-il cette performance énergétique, quels éléments
> du bâtiment l'expliquent, où sont les faiblesses, et que peut-on réellement
> améliorer ?

## 1. Principe fondamental : ne jamais inventer

Trois états pour chaque information recherchée :

1. **Trouvée** → extraite, structurée, restituée.
2. **Partiellement déterminable** → on restitue uniquement ce qui peut être affirmé.
3. **Absente ou indéterminable** → on l'indique : « Information non précisée dans le DPE ».

Interdiction absolue de transformer une absence en hypothèse présentée comme un
fait. **Une donnée manquante est elle-même une information utile.**

## 2. Le DPE se lit comme un bâtiment

Avant toute restitution, il faut pouvoir répondre à : quel bâtiment ?
appartement ou maison ? quelle surface ? quelle époque ? où se situe le logement
dans le bâtiment ? quelles parois donnent sur l'extérieur ? sur des locaux non
chauffés ? comment sont constitués les murs ? sont-ils isolés ? où est
l'isolation ? quelle épaisseur ? quelle performance connue ? la toiture est-elle
isolée ? le plancher bas ? les fenêtres sont-elles toutes performantes ?
existe-t-il plusieurs types de fenêtres ? du simple vitrage subsiste-t-il ?
quels matériaux de menuiserie ? quel chauffage, quelle énergie ? comment l'eau
chaude est-elle produite ? quelle ventilation ? une climatisation ? une
production renouvelable ? quels postes de déperdition ? quelles améliorations
recommandées ?

On ne lit pas une étiquette : on reconstitue le comportement énergétique du bien.

## 3. Rituel DPE — étape 1 : identifier le bien

Adresse ; type de bien ; maison/appartement ; bâtiment concerné ; étage ;
position dans le bâtiment ; année ou période de construction ; surface de
référence ; nombre de niveaux ; caractéristiques générales ; date du DPE ;
numéro ADEME lorsqu'il figure ; méthode et informations méthodologiques.

Distinguer **identité administrative** et **caractéristiques physiques**.

## 4. La vignette DPE — point d'entrée

Résumé visuel immédiatement identifiable : **classe énergétique A→G**, **classe
climat A→G**, puis selon disponibilité : consommation, émissions, estimation des
dépenses, année de référence des prix, surface prise en compte, énergie
principale, principaux systèmes.

La vignette n'est jamais la fin de l'analyse : c'est la porte d'entrée vers
l'explication.

## 5. Enveloppe — priorité absolue

Pour **chaque typologie de mur** : nature ; matériau ; épaisseur ; façade
concernée ; contact (extérieur / local non chauffé / autre) ; isolation présente
ou non ; intérieure / extérieure / répartie ; épaisseur d'isolant ; résistance
thermique ou performance ; date ou période d'isolation.

**Ne jamais résumer plusieurs murs différents par « murs isolés ».** Un logement
peut comporter plusieurs compositions de façades : Verrière conserve ces
différences.

> Question de l'utilisateur : *mes façades sont-elles isolées ? Si oui,
> lesquelles et comment ?*

## 6. Fenêtres et menuiseries — contrôle exhaustif

Pour **chaque famille** : matériau (bois / PVC / aluminium / autre) ; simple,
double ou triple vitrage ; caractéristiques du vitrage ; lame ; performance
thermique ; type d'ouverture ; protections et volets.

**RÈGLE ABSOLUE** — si huit fenêtres sont en double vitrage et qu'une autre
famille est en simple vitrage, Verrière **signale le simple vitrage**.
Interdiction d'afficher « Fenêtres : double vitrage » quand le rapport contient
plusieurs typologies. Quatre états : ✓ tout est performant · ⚠ performance
hétérogène · ⚠ présence de simple vitrage · ? information insuffisante.

## 7. Toiture / plafonds / combles

Toiture ; plafond ; rampants ; combles ; combles perdus ; terrasse ; plancher
haut ; isolation ; matériau isolant ; épaisseur ; performance ; surface
concernée ; environnement adjacent.

> Le logement perd-il de l'énergie par le haut, et sait-on si la toiture ou le
> plafond est isolé ?

## 8. Planchers bas

Même exigence : plancher bas ; terre-plein ; vide sanitaire ; cave ; sous-sol ;
local non chauffé ; extérieur ; isolation ; épaisseur ; performance ; surface.
Jamais secondaire.

## 9. Ponts thermiques

Les identifier et les expliquer quand le rapport les fournit. Explication simple
d'abord — même isolé, certaines jonctions laissent passer la chaleur — puis
accès à la donnée technique. Ne pas noyer l'utilisateur dans les coefficients.

## 10. Chauffage

**Tous** les systèmes, pas seulement le principal. Type ; énergie ; individuel /
collectif ; générateur ; chaudière ; pompe à chaleur ; radiateurs ; convecteurs ;
poêle ; réseau ; rendement ; année ou ancienneté ; régulation ; thermostat ;
programmation ; équipements complémentaires. **Deux systèmes → les deux apparaissent.**

## 11. Eau chaude sanitaire

Système ; énergie ; ballon / chaudière / thermodynamique / autre ; individuel ou
collectif ; volume ; performance ; ancienneté ; association éventuelle au chauffage.

## 12. Ventilation

Naturelle ; VMC simple flux ; hygroréglable ; double flux ; entrées d'air ;
système collectif ; autre. Expliquer l'enjeu : renouveler l'air en limitant les
pertes et les problèmes d'humidité.

## 13. Refroidissement / confort d'été

Climatisation ; PAC réversible ; protections solaires ; volets ; éléments
influençant le confort d'été ; inconforts signalés. **Un vrai volet CONFORT
D'ÉTÉ**, pas une ligne perdue au milieu du rapport.

## 14. Énergies renouvelables

Photovoltaïque ; solaire thermique ; pompe à chaleur ; bois ; autres. Faire
comprendre leur rôle réel dans le logement.

## 15. Déperditions — la carte du bâtiment

Quand les données le permettent : murs ; fenêtres et menuiseries ; toiture et
plafond ; plancher bas ; ponts thermiques ; renouvellement d'air et ventilation ;
autres postes. L'utilisateur doit voir **OÙ PART LA CHALEUR** — représentation
visuelle du logement, postes majeurs immédiatement saillants.

## 16. Comprendre la classe

Pas « DPE : D » mais « pourquoi suis-je D ? », à partir des éléments réellement
présents : enveloppe, isolation, vitrage, chauffage, ECS, ventilation,
déperditions, énergie utilisée. **Créer le lien entre résultat et causes.**

## 17. Consommations et coûts

Consommation conventionnelle ; énergie primaire ; énergie finale lorsqu'elle
figure ; émissions ; estimation annuelle des coûts ; fourchette basse et haute ;
année de référence.

**Ne jamais confondre consommation conventionnelle du DPE et facture énergétique
réelle de l'occupant** — la différence doit être explicitée.

## 18. Recommandations

Toutes récupérées, distinguées quand le DPE le permet :

- **Priorité 1 — travaux structurants** : enveloppe, isolation, menuiseries.
- **Priorité 2 — systèmes** : chauffage, ECS, ventilation, régulation.
- **Priorité 3 — optimisations et actions complémentaires.**

Pour chacune : élément concerné ; problème identifié ; recommandation ; gain ou
classe projetée lorsque le DPE la fournit ; estimation financière lorsqu'elle est
fournie ; précautions ou séquencement indiqué.

Ne jamais transformer automatiquement une recommandation générique du DPE en
prescription technique certaine.

## 19. Scénarios de travaux

Écran spécifique lorsqu'ils existent : **AUJOURD'HUI → TRAVAUX → APRÈS**
(classe E → rénovation proposée → classe C), uniquement lorsque ces informations
sont réellement présentes dans le DPE. L'utilisateur doit comprendre l'intérêt du
scénario sans lire plusieurs pages techniques.

## 20. Cohérence interne

Rechercher les incohérences : synthèse annonçant une isolation alors qu'une paroi
est non isolée ; plusieurs vitrages restitués trop simplement ; systèmes
différents selon les sections ; surface incohérente ; données contradictoires ;
équipement présent dans une partie et absent ailleurs.

→ **⚠ POINT À VÉRIFIER** et explication précise de la contradiction. **Verrière
ne tranche jamais arbitrairement entre deux données contradictoires.**

## 21. Hiérarchie de restitution

1. **Je veux savoir** — information immédiatement compréhensible.
2. **Je veux comprendre** — explication pédagogique.
3. **Je veux voir le détail** — caractéristiques techniques.
4. **Je veux retrouver la source** — renvoi vers la partie / page / zone du DPE
   lorsque techniquement disponible.

*Simple en surface. Exhaustif en profondeur.*

## 22. Format : application, jamais reproduction du PDF

Le DPE original est paginé ; Verrière ne l'est pas. Écran principal **MON DPE**,
en cartes : étiquette énergétique · pourquoi cette note · isolation · façades ·
fenêtres · toiture · plancher · chauffage · eau chaude · ventilation · confort
d'été · déperditions · coût énergétique · travaux recommandés · après travaux ·
données techniques · points à vérifier.

Chaque carte ouvre un niveau supplémentaire. Aucune sensation de rapport
administratif.

## 23. Design

Univers Verrière : vert émeraude, ivoire, lumière, architecture, profondeur,
relief subtil, chaleur, élégance, esprit cabinet d'architecture contemporain,
pictogrammes premium, hiérarchie extrêmement lisible.

Le DPE conserve sa couleur réglementaire A→G comme élément visuel fort ; le reste
ne devient pas un festival de couleurs. **La couleur informe, la lumière
hiérarchise, l'architecture structure.**

## 24. La plume Verrière — deux profondeurs

- **Plume 1, immédiate** : « Vos murs sont partiellement isolés. »
- **Plume 2, explicative** : « Le DPE décrit plusieurs types de parois. Certaines
  disposent d'une isolation identifiée, tandis que d'autres ne permettent pas de
  confirmer le même niveau d'isolation. Cela peut créer des performances
  différentes selon les façades. »

Puis accès au niveau technique. Claire, précise, rassurante sans minimiser,
pédagogique, jamais infantilisante, jamais alarmiste, techniquement irréprochable.

## 26. Non-régression

Toute nouvelle typologie rencontrée — nouveau libellé, nouvelle présentation,
nouvelle manière de décrire une paroi, donnée inconnue, variante d'un autre
logiciel, cas complexe, structure non reconnue — **enrichit Verrière**. On ne
bricole pas le dossier concerné :

1. comprendre le cas ;
2. identifier la règle générale ;
3. améliorer le moteur de lecture ;
4. ajouter le cas au corpus de test ;
5. vérifier les anciens cas ;
6. empêcher toute régression.

**Chaque DPE difficile doit rendre Verrière meilleure.**

## 27. Traçabilité

DONNÉE SOURCE → EXTRACTION → NORMALISATION → INTERPRÉTATION → EXPLICATION
VERRIÈRE → AFFICHAGE. Il faut toujours pouvoir répondre : « pourquoi Verrière
affirme-t-elle cela ? » et retrouver la donnée source.

## 28. Test de sortie

Se placer successivement dans la peau :

1. d'un **particulier** — « est-ce que je comprends mon logement ? » ;
2. d'un **diagnostiqueur** — « est-ce techniquement fidèle au DPE ? » ;
3. d'un **professionnel du bâtiment** — « est-ce que je comprends rapidement les
   caractéristiques du bâti ? » ;
4. d'un **développeur** — « chaque affirmation est-elle reliée à une donnée ? » ;
5. d'un **contrôleur qualité** — « une information importante a-t-elle disparu ? ».

**Une seule réponse insatisfaisante impose de reprendre le traitement.**

## 29. Objectif final

Verrière n'est pas un résumeur de PDF : c'est une **interface de compréhension du
bâtiment**.

MA NOTE → POURQUOI ? → COMMENT EST CONSTRUIT ET ISOLÉ MON LOGEMENT ? → OÙ SONT
LES PERTES ? → QUELS ÉQUIPEMENTS CONSOMMENT ? → QU'EST-CE QUI EST DÉJÀ
PERFORMANT ? → QU'EST-CE QUI DOIT ÊTRE AMÉLIORÉ ? → QUELS TRAVAUX SONT PROPOSÉS ?
→ QUEL POURRAIT ÊTRE LE RÉSULTAT APRÈS TRAVAUX ?

## 30. Contrainte absolue et permanente

Jamais de choix entre **BEAU / COMPLET / SIMPLE / TECHNIQUE / FIABLE** : les cinq
simultanément.

- Aucune donnée critique sacrifiée pour simplifier l'interface.
- Aucune complexité technique imposée quand elle peut être expliquée.
- Aucune information inventée pour combler un manque.
- Aucune variante de paroi, fenêtre ou équipement noyée dans une moyenne trompeuse.
- Aucune contradiction silencieusement arbitrée.
- Aucun nouveau cas rencontré perdu.

Le travail n'est terminé que lorsque Verrière permet de **voir, comprendre et
expliquer** le DPE sans trahir une seule information du diagnostic.
