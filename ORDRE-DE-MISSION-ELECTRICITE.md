# ORDRE DE MISSION MAÎTRE — VERRIÈRE

## DIAGNOSTIC ÉLECTRICITÉ — LECTURE TOTALE, ANOMALIES, MESURES COMPENSATOIRES, LOCALISATION ET EXPLICATION DU BIEN

*Donné par Aude le 21/08/2026. Référence permanente. Transcrit sans coupe.*

## 0. STATUT DE CET ORDRE

Cet ordre de mission constitue la référence permanente pour toute lecture,
extraction, analyse et restitution d'un état de l'installation intérieure
d'électricité dans Verrière.

**CONTRAINTE ABSOLUE ET PERMANENTE**

EXCELLENCE.
LECTURE TOTALE.
FIDÉLITÉ ABSOLUE AU RAPPORT.
AUCUNE ANOMALIE PERDUE.
AUCUNE MESURE COMPENSATOIRE PERDUE.
AUCUNE CONSTATATION DIVERSE PERDUE.
AUCUNE LIMITE DE CONTRÔLE PERDUE.
AUCUNE INFORMATION INVENTÉE.

Claude n'a pas le droit de considérer que le rapport est compris après lecture
de sa seule synthèse. Il doit lire le rapport électrique dans son intégralité et
reconstruire l'état du bien.

Verrière ne doit pas simplement répondre : « Installation électrique avec
anomalies. »

Elle doit pouvoir expliquer : Qu'est-ce qui pose problème ? Où ? Pourquoi ? Quel
risque cela représente-t-il ? Plusieurs occurrences sont-elles concernées ?
Existe-t-il une mesure compensatoire ? Qu'est-ce qui n'a pas pu être contrôlé ?
Et que faut-il retenir de l'installation dans son ensemble ?

## 1. PRINCIPE MAÎTRE : ON COLLE LE RAPPORT, VERRIÈRE EXPLIQUE LE BIEN

L'utilisateur fournit son diagnostic. Verrière doit reconstruire :

LE BIEN → L'INSTALLATION ÉLECTRIQUE → LES ÉQUIPEMENTS DE SÉCURITÉ → LES CIRCUITS
→ LES LOCAUX CONCERNÉS → LES ANOMALIES → LEURS LOCALISATIONS → LES MESURES
COMPENSATOIRES → LES POINTS NON CONTRÔLÉS → LES CONSTATATIONS DIVERSES → LES
RISQUES À COMPRENDRE

La finalité n'est pas de recopier le diagnostic. La finalité est de transformer
un rapport technique en représentation intelligible de l'installation électrique
du logement.

## 2. PREMIÈRE RÈGLE : NE JAMAIS INVENTER

Chaque information doit avoir un statut :

- **INFORMATION TROUVÉE** → restituer fidèlement.
- **INFORMATION PARTIELLE** → restituer uniquement ce qui est connu.
- **INFORMATION NON PRÉCISÉE** → afficher : « Information non précisée dans le rapport. »
- **POINT NON CONTRÔLÉ** → afficher clairement : « Ce point n'a pas pu être vérifié lors du diagnostic. »

Il est interdit de transformer NON CONTRÔLÉ en CONFORME ou en ABSENCE
D'ANOMALIE.

## 3. LE RITUEL ÉLECTRICITÉ VERRIÈRE

Chaque diagnostic doit obligatoirement suivre cet ordre de lecture :

1. Identifier le bien.
2. Identifier le périmètre de l'installation examinée.
3. Lire la synthèse générale.
4. Identifier tous les domaines de sécurité contrôlés.
5. Lire chaque anomalie individuellement.
6. Identifier sa référence.
7. Lire son libellé complet.
8. Identifier sa localisation lorsque donnée.
9. Identifier si plusieurs éléments sont concernés.
10. Identifier une éventuelle mesure compensatoire.
11. Conserver le lien anomalie ↔ mesure compensatoire.
12. Lire toutes les constatations diverses.
13. Identifier tous les points n'ayant pu être vérifiés.
14. Identifier les limitations du diagnostic.
15. Lire les informations complémentaires.
16. Lire les recommandations/commentaires éventuellement présents.
17. Croiser synthèse et détail.
18. Rechercher les contradictions.
19. Construire l'explication Verrière.
20. Effectuer une deuxième lecture de contrôle.

**Aucune étape ne peut être omise.**

## 4. IDENTIFICATION DU BIEN

Extraire, lorsque disponible : adresse ; appartement/maison ; bâtiment ; étage ;
lot ; dépendances ; propriétaire ou donneur d'ordre lorsque pertinent ; date du
diagnostic ; date de visite ; opérateur ; référence du rapport ; caractéristiques
utiles du logement ; installation alimentée ou non au moment du diagnostic.

L'utilisateur doit savoir immédiatement : quel bien et quelle installation ont
été examinés ?

## 5. PÉRIMÈTRE : COMPRENDRE CE QUE LE DIAGNOSTIC EXAMINE

Il s'agit d'un diagnostic de sécurité de l'installation intérieure existante.
Verrière ne doit pas le présenter comme « une certification complète de
conformité de toute l'installation électrique ». Elle doit expliquer simplement
son périmètre : le diagnostic examine l'installation concernée, dans les limites
de la mission et de ce qui est accessible/contrôlable.

## 6. LA VIGNETTE ÉLECTRICITÉ

Vignette immédiatement compréhensible, affichant selon le dossier :
**ÉLECTRICITÉ — Aucune anomalie identifiée** ou **Anomalie(s) identifiée(s)**.

Puis des indicateurs : nombre de familles d'anomalies ; mesures compensatoires ;
points non vérifiés ; constatations diverses ; éventuellement point(s)
nécessitant une attention particulière.

**La vignette ne doit jamais réduire tout le diagnostic à un simple voyant rouge
ou vert.**

## 7. LES GRANDES FAMILLES DE SÉCURITÉ

**APPAREIL GÉNÉRAL DE COMMANDE ET DE PROTECTION** — l'utilisateur doit
comprendre : peut-on couper rapidement l'électricité du logement en cas de
problème ?

**PROTECTION DIFFÉRENTIELLE** — identifier les dispositifs différentiels et les
anomalies associées. Ces dispositifs participent à la protection des personnes
contre certains risques de choc électrique.

**PRISE DE TERRE ET MISE À LA TERRE** — analyser : prise de terre ; conducteurs
de protection ; continuité ; prises de courant ; circuits concernés ; éléments
métalliques concernés ; anomalies et mesures compensatoires.

**PROTECTION CONTRE LES SURINTENSITÉS** — dispositifs de protection ; circuits
concernés ; adaptations ; fusibles/disjoncteurs lorsque mentionnés ; anomalies du
tableau ou des circuits.

**SALLE D'EAU / BAIGNOIRE / DOUCHE** — traitement particulièrement lisible :
liaison équipotentielle ; volumes/zones ; appareillages ; matériels ;
distances/protections concernées ; anomalies ; mesures compensatoires
éventuelles. **Les anomalies dans une salle d'eau ne doivent jamais être noyées
dans une liste générale.**

**RISQUES DE CONTACT DIRECT** — tout matériel ou élément susceptible de
permettre un contact avec des parties actives accessibles lorsque cette anomalie
est signalée.

**MATÉRIELS VÉTUSTES OU INADAPTÉS** — ne pas traduire automatiquement
« vétuste » par « toute l'installation doit être refaite ». Restituer exactement
l'information du rapport puis l'expliquer.

**CONDUCTEURS** — conducteurs mal protégés ; protection mécanique insuffisante ;
conducteurs accessibles ; problèmes signalés ; localisation disponible.

**INSTALLATIONS PARTICULIÈRES** — piscine ; bassin ; dépendance ; extérieur ;
parties communes/parties privatives ; équipements particuliers ; autres
installations citées.

## 8. UNE ANOMALIE = UN OBJET COMPLET

Chaque anomalie doit être stockée avec au minimum : RÉFÉRENCE · FAMILLE ·
LIBELLÉ SOURCE · LOCALISATION · ÉLÉMENT CONCERNÉ · NOMBRE/PLURALITÉ SI
DÉDUCTIBLE · MESURE COMPENSATOIRE ÉVENTUELLE · EXPLICATION VERRIÈRE · SOURCE
DANS LE RAPPORT.

Jamais simplement « B3 — anomalie terre ». Cette simplification est
insuffisante.

## 9. SI UNE ANOMALIE EXISTE PLUSIEURS FOIS

**POINT ABSOLUMENT ESSENTIEL.** Lorsque le rapport indique ou permet clairement
d'identifier plusieurs occurrences, Verrière ne doit pas réduire l'information à
une occurrence unique.

« Plusieurs prises ne sont pas reliées à la terre » ne devient jamais « Une prise
présente un problème de terre ».

Inversement, si le rapport ne localise qu'un exemple d'une anomalie susceptible
d'être plus étendue, Verrière ne doit pas inventer un nombre. Elle doit utiliser
« Au moins un élément concerné selon le rapport » ou toute formulation fidèle à
la donnée source.

## 10. LOCALISATION DES ANOMALIES

Récupérer toute localisation disponible : séjour ; cuisine ; chambre ; salle de
bains ; WC ; garage ; cave ; extérieur ; tableau électrique ; prise ; circuit ;
équipement ; autre emplacement.

Si une anomalie comporte plusieurs localisations : **conserver toutes celles
données.**

L'application doit permettre **VOIR PAR ANOMALIE** et également **VOIR PAR
PIÈCE**.

## 11. ATTENTION : LOCALISATION NON EXHAUSTIVE

Distinguer : le constat d'une famille d'anomalies ; les exemples/localisations
mentionnés dans le rapport ; l'étendue réelle qui peut être supérieure lorsque le
rapport le précise ou que sa méthodologie ne garantit pas une localisation
exhaustive.

Verrière ne doit jamais laisser croire « il n'existe qu'une prise concernée »
simplement parce qu'une seule localisation est citée.

## 12. MESURE COMPENSATOIRE — RÈGLE FONDAMENTALE

**UNE MESURE COMPENSATOIRE NE SUPPRIME PAS L'ANOMALIE.** Elle signifie qu'une
disposition est correctement mise en œuvre pour limiter le risque associé à une
situation qui reste néanmoins identifiée dans le diagnostic.

Architecture obligatoire : ANOMALIE → RISQUE / EXPLICATION → MESURE
COMPENSATOIRE PRÉSENTE ? (OUI / NON / NON PRÉCISÉ) → CE QUE CELA CHANGE.

## 13. INTERDICTION DE FAIRE DISPARAÎTRE UNE ANOMALIE COMPENSÉE

Si le rapport signale une absence de conducteur de protection sur certains
circuits et indique une mesure compensatoire correctement mise en œuvre,
Verrière ne doit **JAMAIS** conclure « Pas d'anomalie grâce au différentiel ».

Elle doit restituer : l'anomalie identifiée ; la mesure compensatoire qui limite
le risque associé ; et le fait que la mesure réduit le risque mais ne fait pas
disparaître la situation signalée.

## 14. RELATION ANOMALIE ↔ MESURE COMPENSATOIRE

Chaque mesure compensatoire doit être attachée à l'anomalie qu'elle compense.
**Interdiction de faire une liste séparée sans correspondance.**

Anomalie A → mesure compensatoire A. Anomalie B → aucune mesure indiquée.
Anomalie C → mesure compensatoire C.

## 15. NE JAMAIS CONFONDRE « COMPENSÉ » ET « RÉPARÉ »

COMPENSÉ ≠ RÉPARÉ · COMPENSÉ ≠ SUPPRIMÉ · COMPENSÉ ≠ CONFORME
COMPENSÉ = RISQUE LIMITÉ PAR UNE DISPOSITION RECONNUE DANS LE RAPPORT

Cette nuance est obligatoire dans toutes les plumes Verrière.

## 16. LES CONSTATATIONS DIVERSES SONT PRIORITAIRES

Lire intégralement : constatations diverses ; observations ; commentaires ;
informations complémentaires ; notes ; particularités de l'installation ;
éléments non couverts ; éléments concernant l'environnement de l'installation.

**INTERDICTION ABSOLUE** de les reléguer comme du « texte secondaire ». Une
constatation diverse peut expliquer une installation atypique ou une limite
majeure de l'examen. Créer une carte **AUTRES CONSTATATIONS**.

## 17. POINTS NON VÉRIFIÉS

Pour chacun : QUEL POINT ? POURQUOI ? QUELLE PARTIE DU BIEN ? QUELLE CONSÉQUENCE
POUR LA LECTURE ?

Causes possibles, uniquement si mentionnées : installation non alimentée ;
équipement inaccessible ; tableau inaccessible ; impossibilité de réaliser un
essai ; impossibilité de réaliser une mesure ; autre limitation.

Créer une carte dédiée **CE QUI N'A PAS PU ÊTRE CONTRÔLÉ**.

## 18. INSTALLATION NON ALIMENTÉE

Information majeure, à faire apparaître immédiatement. Verrière doit expliquer
que certains essais de fonctionnement peuvent ne pas avoir été réalisables. Ne
jamais présenter ces contrôles comme réussis ou conformes.

## 19. LES LIMITES DU DIAGNOSTIC

Rechercher toutes les mentions indiquant que certaines parties sont : non
visibles ; non accessibles ; cachées ; incorporées ; derrière du mobilier ;
nécessitant un démontage ; nécessitant une détérioration ; non contrôlables dans
les conditions de la mission.

Créer **LIMITES DE L'EXAMEN**.

## 20. TABLEAU ÉLECTRIQUE

Carte spécifique **TABLEAU & PROTECTIONS** : tableau ; appareil général ;
disjoncteurs ; différentiels ; protections ; accessibilité ; éventuelles
anomalies ; vétusté signalée ; localisation ; autres constatations.

Le tableau est le centre de contrôle visuel de l'application Électricité.

## 21. TERRE

Carte forte **MISE À LA TERRE**. Elle répond simplement : l'installation
dispose-t-elle des dispositifs de mise à la terre attendus selon ce que le
diagnostic a pu contrôler ? Puis : anomalies ; circuits concernés ; prises
concernées ; continuité lorsqu'elle est signalée ; mesure compensatoire ; points
non vérifiés.

## 22. SALLE DE BAINS / SALLES D'EAU

Carte spécifique **ÉLECTRICITÉ & EAU** : localisation ; anomalie ; élément
concerné ; explication ; mesure compensatoire éventuelle ; source.

## 23. VÉTUSTÉ

**MATÉRIEL VÉTUSTE SIGNALÉ** puis : où ? quel matériel ? quel libellé exact ?
Ne jamais transformer automatiquement en « installation électrique entièrement
vétuste ».

## 24. NIVEAUX DE GRAVITÉ : NE PAS LES INVENTER

Ne jamais créer arbitrairement « danger faible / moyen / fort » si cette
classification n'existe pas dans la source ou dans un référentiel expressément
validé pour Verrière. La pédagogie peut expliquer la nature du risque, elle ne
doit pas inventer une hiérarchie réglementaire.

## 25. « POURQUOI EST-CE IMPORTANT ? »

PLUME 1 — IMMÉDIATE · PLUME 2 — EXPLICATIVE · MESURE COMPENSATOIRE · SOURCE.

## 26. ORGANISATION PAR PIÈCES

**MON LOGEMENT PIÈCE PAR PIÈCE.** Une même anomalie peut apparaître dans
plusieurs pièces. Elle ne doit pas être dupliquée dans le moteur comme plusieurs
familles différentes, mais ses différentes localisations doivent être conservées.

## 27. ORGANISATION PAR FAMILLE TECHNIQUE

Coupure générale · Protection différentielle · Terre · Protection des circuits ·
Salle d'eau · Contact direct · Matériel vétuste/inadapté · Conducteurs ·
Installations particulières · Autres constatations.

L'utilisateur choisit **VOIR MON BIEN** ou **COMPRENDRE LES PROBLÈMES
TECHNIQUES**.

## 28. ÉCRAN « CE QU'IL FAUT RETENIR »

MON INSTALLATION · les points principaux (3 à 5 maximum en surface) · mesures
compensatoires · points non contrôlés · pièces particulièrement concernées ·
constatations diverses. Puis : voir toutes les anomalies.

**Aucune information ne doit être supprimée : seulement hiérarchisée.**

## 29. ÉCRAN « TOUTES LES ANOMALIES »

Chaque carte : INTITULÉ SIMPLE · Où ? · Que dit le rapport ? (libellé fidèle) ·
Qu'est-ce que cela signifie ? · Mesure compensatoire ? · Que compense-t-elle ? ·
Voir la donnée technique · Voir dans le rapport.

## 30. FORMAT APPLICATION — JAMAIS PAGINATION

Le PDF est paginé. Verrière ne doit jamais devenir un PDF décoré.

MON ÉLECTRICITÉ : Vignette → Ce qu'il faut retenir → Mon installation → Tableau
& protections → Mise à la terre → Mes pièces → Salle d'eau → Toutes les
anomalies → Mesures compensatoires → Constatations diverses → Points non
vérifiés → Limites du diagnostic → Données techniques → Rapport source.

Navigation fluide par cartes, accordéons, filtres et liens croisés.

## 31. LE MOTEUR DOIT CROISER LES INFORMATIONS

Comparer : SYNTHÈSE ↕ ANOMALIES DÉTAILLÉES ↕ MESURES COMPENSATOIRES ↕
CONSTATATIONS DIVERSES ↕ POINTS NON VÉRIFIÉS ↕ LIMITES ↕ COMMENTAIRES/PHOTOS.

Une incohérence doit créer **⚠ POINT À VÉRIFIER**.

## 32. MOTEUR DE CONTRADICTIONS

- La synthèse indique une anomalie mais aucune anomalie détaillée n'est extraite → **BLOCAGE**.
- Une anomalie indique une mesure compensatoire mais Verrière l'affiche comme « corrigée » → **BLOCAGE**.
- Un point n'a pas pu être vérifié mais Verrière l'affiche comme « conforme » → **BLOCAGE**.
- Le rapport comporte 5 lignes d'anomalies mais l'application n'en restitue que 4 → **BLOCAGE**.
- Une anomalie mentionne plusieurs localisations et Verrière n'en garde qu'une sans avertissement → **BLOCAGE**.

## 33. CONTRÔLE DU NOMBRE DE LIGNES

Compter les lignes d'anomalies détectées dans le rapport et comparer aux lignes
structurées dans Verrière. Les deux doivent correspondre, sauf justification
explicite de normalisation documentée. Même logique pour les mesures
compensatoires, les constatations diverses et les points non vérifiés.

## 34. TEST DE LA PETITE LIGNE

Deuxième lecture obligatoire pour rechercher : note ; astérisque ; localisation ;
renvoi ; réserve ; mesure compensatoire ; constatation diverse ; point non
contrôlé ; installation non alimentée ; commentaire ; limite ; tableau annexe ;
précision après une anomalie.

« Quelle information importante pourrais-je avoir ratée parce qu'elle n'est pas
dans la grosse synthèse ? »

## 35. PHOTOS

Récupérer leur association ; conserver leur légende ; conserver la référence ;
les rattacher à l'anomalie concernée ; permettre leur consultation depuis la
fiche de l'anomalie.

Ne jamais interpréter seul une photo contre le texte du diagnostiqueur. La photo
illustre. Le rapport fait foi pour l'extraction Verrière.

## 36. CONTRÔLE DE COMPLÉTUDE OBLIGATOIRE

Bien identifié · Périmètre compris · Installation alimentée/non alimentée
vérifiée · Synthèse lue · Toutes les familles contrôlées · Toutes les lignes
d'anomalies lues · Toutes les références récupérées · Tous les libellés conservés
· Toutes les localisations récupérées · Pluralité des éléments respectée · Aucune
anomalie diluée · Toutes les mesures compensatoires recherchées · Chaque mesure
compensatoire rattachée à son anomalie · Aucune anomalie compensée supprimée ·
Compensé jamais présenté comme réparé · Appareil général analysé · Protection
différentielle analysée · Mise à la terre analysée · Protection contre les
surintensités analysée · Salle d'eau analysée · Contacts directs analysés ·
Matériels vétustes/inadaptés analysés · Conducteurs analysés · Installations
particulières recherchées · Constatations diverses intégralement lues · Points
non vérifiés identifiés · Limites de l'examen identifiées · Photos pertinentes
reliées · Synthèse comparée aux anomalies · Contradictions recherchées · Sources
conservées · Aucune donnée inventée · Aucune gravité inventée · Aucune conformité
inventée · Deuxième lecture réalisée · Restitution par pièce disponible si
possible · Restitution par thème disponible · Format application respecté ·
Explication compréhensible par un non-électricien.

**UNE SEULE CASE NON CONTRÔLÉE = DOSSIER NON TERMINÉ.**

## 37. TEST « ZÉRO PERTE »

Comparer RAPPORT ORIGINAL et DONNÉES VERRIÈRE : chaque anomalie importante
existe-t-elle encore ? chaque mesure compensatoire ? chaque localisation
importante ? chaque point non vérifié ? chaque constatation diverse ? chaque
nuance ? Si non : **ÉCHEC**.

## 38. TEST « RECONSTRUIRE LE BIEN »

Où se trouve le tableau ? Existe-t-il une anomalie sur l'appareil général ? La
protection différentielle présente-t-elle une anomalie ? La terre ? Certaines
prises ou certains circuits sont-ils concernés ? Combien de types d'anomalies
sont relevés ? Où sont-elles localisées ? Existe-t-il plusieurs occurrences ? Une
mesure compensatoire existe-t-elle ? Pour quelle anomalie ? Qu'est-ce qu'elle
limite ? Quels contrôles n'ont pas pu être effectués ? Existe-t-il des anomalies
en salle d'eau ? des matériels vétustes ? des risques de contact direct signalés ?
des constatations diverses ? des limitations importantes ? Que doit retenir le
propriétaire en priorité ?

Si l'information existe dans le rapport et que Claude ne sait pas répondre :
**TRAITEMENT INCOMPLET**.

## 39. APPRENTISSAGE PERMANENT

Devant un autre logiciel, une autre structure, une nouvelle présentation, un
nouveau tableau, un nouveau libellé, un code différent, une nouvelle formulation
de mesure compensatoire, de constatation diverse ou de point non vérifié :

1. comprendre le cas ;
2. l'intégrer au référentiel ;
3. créer une règle générale ;
4. ajouter un cas de test ;
5. tester les anciens rapports ;
6. vérifier qu'aucune régression n'est créée.

**Une difficulté rencontrée une fois doit rendre Verrière définitivement
meilleure.**

## 40. PLUME VERRIÈRE : PAS DE PANIQUE, PAS DE MINIMISATION

Interdit : « Votre installation est dangereuse. » si le rapport ne justifie pas
cette affirmation générale. Interdit également : « Rien de grave. » si Verrière
n'a aucune base pour hiérarchiser ainsi.

Préférer : ce que le rapport constate ; pourquoi c'est important ; ce qui limite
éventuellement le risque ; ce que Verrière ne doit pas prétendre.

## 41. DESIGN VERRIÈRE ÉLECTRICITÉ

Univers général Verrière : vert émeraude ; ivoire ; architecture ; lumière ;
relief ; matière ; chaleur ; sobriété premium.

Pour l'électricité : **jaune lumineux** comme couleur fonctionnelle
d'identification, jamais jaune criard. Le jaune sert à identifier la
micro-application, éclairer certains éléments, guider la lecture. **Pas à
transformer toute l'interface en panneau de danger.**

L'ensemble doit évoquer un bureau d'architecte qui explique une installation
technique complexe avec une grande précision.

## 42. OBJECTIF ULTIME

Le particulier doit pouvoir dire : « Je sais exactement ce que le diagnostiqueur
a trouvé. Je sais où. Je comprends ce que cela signifie. Je sais quelles
anomalies apparaissent plusieurs fois ou peuvent concerner plusieurs éléments. Je
vois quelles anomalies bénéficient d'une mesure compensatoire. Je sais que cette
mesure ne supprime pas l'anomalie. Je sais ce que l'opérateur n'a pas pu
vérifier. Je peux retrouver chaque information dans mon rapport. »

INTERDICTION DE FAIRE DISPARAÎTRE UNE ANOMALIE PARCE QU'UNE MESURE COMPENSATOIRE EXISTE.
INTERDICTION DE CONFONDRE COMPENSATION ET CORRECTION.

INTERDICTION D'INVENTER UNE GRAVITÉ.
INTERDICTION D'INVENTER UNE CONFORMITÉ.

**CONTRAINTE ABSOLUE D'EXCELLENCE, DE COMPLÉTUDE ET DE NON-RÉGRESSION.**

Verrière n'est pas un résumé du diagnostic électrique. Verrière est la
traduction structurée, exhaustive, localisée et pédagogique de l'état réel décrit
par le diagnostiqueur.
